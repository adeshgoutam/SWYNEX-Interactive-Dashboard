# SWYNEX Interactive Sales Dashboard

## Project Overview
An interactive sales dashboard created using Microsoft Power BI and the Online Retail dataset. The dashboard helps explore revenue trends, country-wise sales and product performance.

## Objectives
- Track key sales performance indicators.
- Analyze monthly revenue trends.
- Identify the top 10 countries by revenue.
- Identify the top 10 products by revenue.
- Explore sales using interactive country and date slicers.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Excel/CSV

## Key Performance Indicators
- Total Revenue
- Total Orders
- Units Sold
- Unique Customers

## Dashboard Visuals
1. Monthly Revenue Trend — line chart
2. Top 10 Countries by Revenue — bar chart
3. Top 10 Products by Revenue — bar chart
4. Country and Date slicers for interactive filtering

## Dataset
Online Retail transaction data. Revenue is calculated using Quantity × UnitPrice. The displayed currency is GBP (£).
